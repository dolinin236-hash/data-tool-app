Что такое Base64?

Base64 — это способ кодирования бинарных данных в текстовый формат. Используется для вложения данных в email, HTML, JSON и другие текстовые форматы.

Когда используется Base64?

  • Встраивание изображений в HTML/CSS
  • Передача данных через API
  • Кодирование файлов в email
  • Хранение бинарных данных в базах

Как работает конвертер?

Введите текст или Base64-строку, нажмите «Кодировать» или «Декодировать». Всё происходит в вашем браузере — данные никуда не отправляются.
