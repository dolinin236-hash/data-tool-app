Что такое Base64?

Base64 — это бинарно-текстовый кодировщик, преобразующий бинарные данные в текстовый формат ASCII. Название происходит от 64 основных символов, используемых в коде: A-Z, a-z, 0-9, +, /.

Где используется Base64?

  • Email (MIME) — вложение бинарных файлов в текстовые письма
  • HTML/CSS — встраивание изображений (data URI)
  • JSON API — передача бинарных данных через текстовые протоколы
  • localStorage — хранение бинарных данных в браузере
  • JWT токены — кодирование заголовков и полезной нагрузки

Как работает Base64 кодирование?

Base64 преобразует каждые 3 байта входных данных в 4 символа из 64-символьного набора. Это означает, что закодированные данные на 33% больше исходных. Для декодирования применяется обратный алгоритм.

Почему DataTool безопасен?

Все операции кодирования и декодирования происходят в вашем браузере. Данные никуда не отправляются — полная конфиденциальность.
